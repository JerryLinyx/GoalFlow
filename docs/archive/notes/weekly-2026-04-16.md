# Weekly Summary (2026-04-16)

> Archived note. This weekly summary reflects an older SafeSim iteration.

## 本周做了什么

- 把 GoalFlow 从原始 `camera + lidar` 输入改造成了 Safe-Sim 版本的 `map + agent` 输入。
- 跑通了 `filtered` 五个 case 的完整训练、验证、推理链路。
- 在 V2 中加入了：
  - `ego-ctrl pair token`
  - `all-token cross-attention`
  - `role × case / pair × case` 条件绑定
- 建立了任务对齐评估：
  - `bbox_collision_rate`
  - `hit@2m`
  - `pred_better_than_gt_rate`
  - `selected / random` 对照
- 做了 history 分辨率 A/B，结论是：
  - 单独提高 history 频率，没有带来稳定收益。
- 做了 Plan A baseline 重跑，加入：
  - 固定 validation noise
  - 关闭 early stopping 干扰
  - 物理平滑性诊断

## 目前最清楚的结论

- V2 结构比 V1 更贴任务，危险生成指标更好。
- 纯 imitation loss 不能代表危险生成质量。
- 当前主要问题不是结构不够强，而是：
  - 数据量不足；
  - 训练后期会往 GT 均值坍缩；
  - 轨迹物理平滑性不够。
