# Archived SafeSim Documents

This directory stores historical SafeSim planning notes, baseline notes, and
reports that are no longer the active source of truth for the repository.

These files are preserved for:

- experiment history
- debugging context
- earlier design rationale
- comparison against superseded training pipelines

They should not be treated as the current entrypoint for the project.
